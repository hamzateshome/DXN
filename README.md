## Features

- Six products from the official Ethiopia catalogue, with original product photography.
- Supplement/beverage filters and accessible product dialogs.
- Product-specific WhatsApp enquiries; the visitor reviews and sends the message.
- Distributor-code copy button and official registration guidance.
- Mobile navigation, keyboard controls, reduced-motion support, descriptive images, metadata and favicon.

This is a static marketing site. It does not accept payments or collect enquiry records. No backend, database, account system, or private API key is needed.

## Run locally

Serve the repository root with any static web server. For example:

```sh
python -m http.server 4173 
```

Open http://localhost:4173. Upload the complete website files to a static host. Keep `assets` alongside `index.html`.

## Editing

- Page content: `index.html`
- Design and breakpoints: `styles.css`
- Filters, product information, dialogs and contact links: `app.js`
- Photographs: `assets/`

Update both the HTML product cards and JavaScript product data when changing a product. The distributor name, code, and contact number are deliberately public contact information and appear in several locations.

## Registration and ordering

Visitors must enter 830273935 and verify the sponsor details themselves. Shopping availability depends on DXN and the selected country. The WhatsApp enquiry is the main conversion path.
